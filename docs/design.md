# 디자인: DR.PATCH 진료 책상 (2026-11-18, 인터뷰로 확정)

> 이전 시안(SOC 대시보드·Figma, 와펜·수집 패치, Carbon DR.PATCH 1차)은 모두 폐기했다. 이 문서가 유일한 기준이다.
> 시제품: `prototype/drpatch-desk/index.html` (한 장면, 예시 데이터)

## 1. 한 줄
**DR.PATCH — 서버를 진료하는 패치 박사님.** 화면 전체가 **살짝 기울인 진료 책상**이고, UI는 책상 위 **말랑한 3D 소품**이다.
보이는 이름만 DR.PATCH, 저장소·코드 이름은 `sudo-patch` 그대로 (명세 반영은 아직).

## 2. 인터뷰로 정한 것
| 항목 | 결정 |

## 4. 세계관과 오브제
| 서비스 | 오브제 | 동작 |
|---|---|---|

| 패키지 하나 | **투톤 캡슐**: 왼쪽 = 현재 버전(위험도 색), 오른쪽 = 목표 버전(민트) | 검사 결과에 색이 켜짐, 누르면 톡 튀어나옴 |
| 회차 | **블리스터 팩** 한 판 (최대 3판), 왼쪽 라벨에 회차·날짜 | `plan_built`에 캡슐이 날아와 칸에 들어가고 투명 덮개가 씌워짐 |

| 실행 로그 | **진료 차트**(클립보드) | 이벤트가 한 줄씩 적힘, 누르면 전체 기록 |

## 4-1. 3차 인터뷰로 바뀐 것 (2026-11-18)
- **진짜 책상:** 밝은 나무 상판(나무결 이미지) + 흰 프레임·다리·앞판(청록 띠) + 청록 데스크 패드. 흰 머리카락이 잘 보인다.
- **블리스터 자동 조립:** 실제 계획처럼 회차는 최대 3, 회차당 N개. 판은 회차마다 한 장, 칸 수는 N에 맞춰 이어 붙이고(blister_end + blister_cell×N), 패드에 넘치면 줄 바꿈·축소.
- **안전한 패키지 → 곡반(트레이)**, **회차에 못 든 패키지 → 약병에 남아 '다음 진료'**.
- **특별 알약:** 인기 패키지는 대표색 투톤 + 이니셜 각인 + 모양(캡슐·캐플릿·정제·연질캡슐). 실제 로고는 쓰지 않는다. 나머지는 일반 캡슐.
- 알약 색이 패키지 정체성을 맡으므로 **위험도는 알약 아래 고리 + 블리스터 홈 색 + 종이 배지(글자)**로 보인다.
- 렌더: 그림자 2048, 스탠드 조명, 창문 빛. 접촉 그림자(GTAO)는 처음 2초 평균 프레임이 16.5ms 안일 때만 자동으로 켠다 (`?hq=1` 강제 켜기, `?lq=1` 끄기).

## 4-2. 4차 피드백 반영 (성능·깨짐·가독성)
- **성능:** 굴절 유리(transmission)는 쓰지 않는다 → 일반 반투명. 움직이지 않는 메시(진료실·책상·박사님 몸·알약·블리스터 조각)는 재질별로 합친다. 픽셀 비율 최대 1.5. 측정: 메시 490→205, 이 창 기준 18→51fps.
- **깨짐(z-fighting):** 맞닿는 면은 1~5mm 띄운다 (홈·라벨·패드·바느질·바닥 이음새·시계 눈금 등). 카메라 near 0.5. 벽 모서리에서 띠가 겹치지 않게 길이를 맞춤.
- **수액:** 장식. 관은 거치대에 감아 둔다 (약병·알약으로 들어가지 않음).
- **알약:** 투명 덮개 없음. 약병 안에서는 층마다 4알씩 겹치지 않게. 검사 결과는 약병 위로 떠오르는 이름표, 포장 뒤엔 알약 위 이름표(이름 + 위험도 점). 줌 아웃하면 이름표는 숨긴다.
- **줌:** 카메라가 진료실(천장 포함) 밖으로 나가지 않는 만큼만 줌 아웃.

## 4-4. 병실 소품 · 자유 카메라 (`design/blender/ward.py`)
**크기 기준: 책상 높이 8단위 = 75cm → 1단위 ≈ 9.4cm.** 새 소품은 실제 가구 크기로 만든다.
- 오른쪽 벽: 진료 침대(190×70×75cm, 종이 시트·롤·베개), 2단 발판, 회전 의자, 머리맡 의료 가스 패널·진료등, 칸막이 커튼(머리 쪽에 걷힘), 혈압계, 대기 번호 모니터(TVFace, 글자는 코드)
- 왼쪽 벽: 세면대 세트(거울·비누·소독제·종이 타월·장갑 상자), 진료실 문 + EXIT 표시 + 소화기, 코랄 대기 의자 3개 · 뒤 구석: 키 체중계(기둥은 벽, 저울대는 방 쪽)
- 책상 옆: 처치 카트(소독약·솜통·거즈·곡반·주사기·주사기 폐기통) · 오른쪽 앞: 휠체어, 큰 화분(node_modules)
- 수액 거치대는 실제 높이(≈1.8m)로.
- 카메라(OrbitControls): 드래그 회전 · 오른쪽 드래그/Shift 이동 · 휠 줌 · 더블클릭(또는 0) 처음 시점.
  좌우 ±54°(박사님 뒤로 못 감), 위아래 16°~78°, 시선 중심은 책상 주변 상자 안, 카메라는 방 안 상자 안으로 제한.

## 5. 말투 (능청스러운 박사님)
- 예: "흠, urllib3 1.24.1이라니… 꽤 오래 방치하셨군요." / "Django 5.2는 Python 3.8로는 못 넘어가는군요. 처방 바꿉니다."
- 능청은 **표현에만**. 버전·날짜·심각도는 확인한 값만 쓰고, 없으면 "미상" / "확인 못 함" 그대로.
- 실제 의료 조언으로 읽히는 말("치료", "복용 권장")은 쓰지 않는다.
- Agent 응답 문장은 LLM이 쓰므로 프롬프트(`app/agent/brain.py`)에 말투 규칙을 넣는다 → 고치면 `scripts/run_agent.py`로 실제 확인.

## 7. 꼭 지킬 것
- **데이터는 종이 위에서 평평하게.** 버전·날짜·표·로그는 3D 위에 작게 쓰지 않고, 누르면 펼쳐지는 종이(HTML)에서 또렷하게 보인다.
- **움직임 줄이기:** `prefers-reduced-motion` 또는 화면의 "움직임 줄이기"를 켜면 시점 이동·대기 동작을 멈추고 전환은 즉시 끝낸다.
- **3D를 못 그리는 환경:** 평평한 목록 화면으로 대체한다.
- 빨간 십자가(적십자 표장), 실제 회사·Python·Ubuntu 로고는 쓰지 않는다.
- 오류는 짧은 안내만.

## 8. 구현 메모
- 실시간 3D: Three.js (Vue에서는 직접 쓰거나 TresJS). 장면은 하나.
- **3D 소품은 Blender 스크립트로 만든 .glb** (`design/blender/`): common.py(팔레트·재질·도형) 하나를 모든 소품이 같이 써서 통일감을 지킨다. 바뀌는 글자(회차 라벨·진료 기록)는 모델의 빈 면(Label, Paper)에 코드가 그린다. 코드가 찾는 노드 이름은 props.py·doctor.py 맨 위에 적어 둠.
- 다시 만들기: `blender -b --factory-startup -P design/blender/doctor.py`, `... -P design/blender/props.py`, 합성 미리보기 `... -P design/blender/scene_preview.py`
- 조명: RoomEnvironment 반사 + 방향광 그림자 1개. 투명 재질(transmission)은 약병·덮개·수액 팩에만.
- 화면 구성(대화·처방전·진료 예약·진료 기록)은 이 책상 장면 위에 어떻게 얹을지 **시제품 확인 후** 정한다.
