# agy(제미나이)에게 넘기는 다음 작업 묶음 (2026-11-19)

> 모델: **리뷰는 Neon**(Carbon 대신), **구현은 Hydrogen**, **조사는 Flash**.
> Neon은 아직 써 보지 않은 모델이라, 리뷰 결과에는 반드시 근거(파일:줄)를 붙이게 하고 Claude Code가 하나씩 맞는지 확인한다.
> 진행: **1(리뷰) → 2(구현) → 3(조사)**. 1과 3은 서로 상관없어서 동시에 돌려도 된다.
> 2의 각 작업은 1의 리뷰 결과가 나온 뒤 시작한다. Claude Code가 리뷰 지적 중 그 작업에 해당하는 것을 골라 프롬프트 끝에 덧붙인다.

## 사람이 하는 순서 (작업마다)
1. 같은 폴더에서 터미널을 하나 더 열고 `agy` 실행 → 작업에 적힌 모델 선택
2. **공통 머리말** + 해당 작업 프롬프트를 이어 붙여 넣는다
3. 끝나면 Claude Code에게: `agy/<브랜치> 확인해줘` (리뷰는 `docs/review-….md 확인해줘`)
4. Claude Code가 확인하고 main에 합친 뒤 HANDOFF를 갱신 → 다음 작업

```
끝나면:
- 확인: `.venv/bin/python -m pytest -q` (255개 이상 통과), 화면을 바꿨으면 `cd frontend && npm run build`
- 커밋 메시지는 한국어, 작업 단위로
- docs/HANDOFF.md "지금 하던 것"에 한 줄
- 마지막 보고: 바꾼 파일, 확인한 방법, 못 한 것, 질문
```

### I5 · 캘린더 때문에 옮긴 회차 표시
