## 공부할 때 쓰는 도구
- **실행 로그 탭**: 요청 하나의 이벤트(단계·Tool 호출·LLM 판단·재계획)가 순서대로 남는다. 02 문서를 읽으면서 옆에 띄워 두면 "코드의 이 줄이 로그의 이 줄"로 맞춰 볼 수 있다.
- **`scripts/run_agent.py`**: 화면 없이 Agent 한 번을 실제로 돌려 이벤트를 터미널에 찍는다.
- **테스트**: `pytest -q tests/test_planner.py -k spec_example` 처럼 한 테스트만 돌려 보며 값을 바꿔 본다. 테스트 이름이 곧 "이 기능이 지켜야 할 약속"이다.
- 코드 위치는 줄 번호 대신 **함수 이름**으로 적었다 (줄 번호는 코드를 고치면 바뀐다). 편집기에서 함수 이름으로 검색한다.
